Cloudinary

Cuenta usada para subir fotos desde el panel (productos, carrusel, logo, QRs de pago). Esta pantalla sólo la ves vos: es config de infraestructura del sitio, no de la tienda. Si se vacía, la subida de imágenes queda deshabilitada en todo el panel (se puede seguir cargando fotos por URL).

Dashboard de Cloudinary → Settings → Upload → Upload presets → creá uno unsigned. Ambos valores son públicos (van al navegador para poder subir directo, sin pasar por el backend).

Borrar fotos (opcional)

Con la API Key y el API Secret, al eliminar definitivamente un producto archivado también se borran sus fotos de la cuenta. Sin esto, las fotos quedan en Cloudinary (no bloquea nada). Dashboard → Settings → API Keys. Quedan sólo en el servidor: nunca van al navegador.
